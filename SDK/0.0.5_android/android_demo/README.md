# Android AAR Consumer Demo

This app demonstrates how a downstream Android developer should consume the ASR
SDK without depending on SDK internals.

The demo uses:

```text
dist/asr-sdk-android-0.0.5.aar
dist/asr-model-0.0.5.zip
```

It does not build or link `libasr_sdk.so` directly from the demo project.

## Build

From the repository root:

```bash
export ROOT=/path/to/ASR_wenet
export SDK_ROOT=$ROOT/wenet/SDK/0.0.5_android
export JAVA_HOME=/tmp/asr_android_toolchain/jdk-17.0.19+10
export ANDROID_HOME=/tmp/asr_android_toolchain/android-sdk
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH

$SDK_ROOT/scripts/make_android_demo_apk.sh x86_64
```

The script expects these files to exist:

```text
$SDK_ROOT/dist/asr-sdk-android-0.0.5.aar
$SDK_ROOT/dist/asr-model-0.0.5.zip
```

Output:

```text
$SDK_ROOT/android_demo/app/out/manual-x86_64/app-debug.apk
```

## Runtime Flow

The demo app does the same thing a downstream app should do:

```java
try (InputStream modelZip = getAssets().open("asr-model.zip")) {
    AsrSdk.installModelZip(context, modelZip);
}

try (AsrRecognizer recognizer = AsrSdk.createRecognizer(context)) {
    AsrResult result = recognizer.transcribeWav(wavFile);
    String text = result.getText();
}
```

The SDK hides:

```text
native library loading
model zip extraction
native engine creation
native stream lifecycle
JSON result parsing
```

## Gradle-Style Downstream Integration

For a real downstream app using Gradle, copy the AAR into `app/libs/` and add:

```gradle
repositories {
    flatDir {
        dirs "libs"
    }
}

dependencies {
    implementation(name: "asr-sdk-android-0.0.5", ext: "aar")
}
```

This demo also searches `../dist`, so it can consume the AAR generated by
`scripts/make_android_aar.sh` directly.

Then ship or download the model zip and pass it to:

```java
AsrSdk.installModelZip(context, inputStream);
```

If building this demo with Gradle/Android Studio instead of the manual script,
place the generated model zip at:

```text
app/src/main/assets/asr-model.zip
```

For microphone integration, feed 16 kHz PCM16 frames through
`AsrRecognizer.acceptPcm16(...)`, call `decode()` for partial results, then call
`finish()` for the final result.
